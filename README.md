# Tic-Tac-Toe Pro

A modern and interactive Tic-Tac-Toe game developed using HTML, CSS and JavaScript.

## Features

- Player vs Player mode
- Player vs Computer mode
- Easy, Medium and Hard difficulty
- Smart AI using Minimax algorithm
- Score tracking
- Draw tracking
- Winning cell animation
- 15-second move timer
- Dark mode
- Light mode
- New Round button
- Reset Score button
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Play

1. Select the game mode.
2. Player X starts the game.
3. Click an empty cell to place your mark.
4. Get three marks in a row to win.
5. Three marks can be horizontal, vertical or diagonal.
6. In Computer mode, select the difficulty level.
7. Use New Round to start another round.
8. Use Reset Score to clear the scoreboard.
9. Use the moon/sun button to change the theme.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
